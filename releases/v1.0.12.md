Sideflowの初回公開プレリリースです。ChromeにArc / Dia風のページ内サイドバーを追加します。

## 主な機能

- 左・右サイドバーと小型の下ドック（高さ156px）
- 右スワイプで開く／左スワイプで閉じる（macOSナチュラルスクロール基準）
- 慣性を抑制しながら逆スワイプや新しい加速に反応する入力判定
- Work / Personal / Studioのテーマ・ブックマーク切替とアニメーション
- 実タブの切替・閉じる・ドラッグ並べ替え・タブグループ移動
- ブックマークバーの非破壊インポート。確認画面にファビコンとサイト名を表示
- 上部ギャラリーは6項目から展開／折りたたみ
- 検索欄とサイドバーを利用できる専用新規タブ

## インストール

1. 下のAssetsから `sideflow-1.0.12.zip` をダウンロードし、解凍します。
2. Chromeの `chrome://extensions` でデベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で `sideflow-extension` フォルダを選択します。
4. 既存ページを再読み込みし、新規タブを開き直してください。

`.sha256` を併せて添付しています。Chromeウェブストア版ではありません。

## 検証

- クリーンインストール（npm ci）、本番ビルド
- 単体テスト5件：URL解決、ブックマーク変換、スワイプ判定
- UI／拡張操作テスト4件：テーマ、開閉、左右・下ドック、方向別スワイプ、実タブとグループ操作、新規タブ、プロファイル別インポートと保存
- 配布ZIPとバージョン・必須ファイル・チェックサムを確認

## 既知の制限

- Chrome設定・拡張登録画面・Webストア・他拡張の画面にはサイドバーを埋め込めません。
- 別の新規タブ拡張との競合や、サイトアクセス権限によって使えない場合があります。
- プロファイルはテーマと取り込みブックマークの分離です。Cookieと実タブは共有します。
- 物理トラックパッド、Chrome履歴ジェスチャーとの干渉、全サイトでの挙動は未検証です。そのためプレリリースとして公開します。
- Arc / Diaとは無関係の独立した拡張です。
