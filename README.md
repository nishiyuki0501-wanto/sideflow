# Sideflow

Arc / Dia風のページ内サイドバーを追加するChrome拡張です。React + Tailwind CSSで構築しています。Arc / Diaの公式製品ではありません。

[配布版とリリースノート](https://github.com/nishiyuki0501-wanto/sideflow/releases/tag/v1.0.14)

## インストール

1. Releaseから `sideflow-1.0.14.zip` をダウンロードして解凍します。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、解凍した `sideflow-extension` フォルダを選びます。
4. 更新時は拡張の更新ボタンを押し、使うWebページも再読み込みしてください。新規タブは開き直してください。

Chromeウェブストアへの公開は行っていません。ZIP内のSHA-256ではなく、Releaseに添付した `.sha256` でZIPの整合性を確認できます。

## 機能と操作

- 左・右サイドバー／高さ156pxの下ドックを切り替え、配置を保存。
- ページ上で右スワイプして開き、左スワイプで閉じる。既に目的の状態なら反転しません。
- 同じウィンドウでは開閉状態をタブ切替・ページ再読み込み後にも引き継ぎます。開閉状態はブラウザセッション内に保持し、常時表示の設定は再起動後も保存します。
- macOSのナチュラルスクロール基準で、指を右へ動かす入力は `deltaX < 0`、左へは `deltaX > 0` です。OS設定でスクロール方向を変えると指の方向も変わります。
- 下ドックは画面下端で右／上スワイプして開き、ヘッダー・フッターの左／下スワイプで閉じます。
- サイドバー一覧内の横スワイプはプロファイル切替、縦スクロールは一覧閲覧です。
- 拡張アイコンまたはAlt/Option＋Shift＋Sで開閉。ページ内の×またはEscapeで閉じます。
- 画面端へのホバーで一時表示。ヘッダーのピンで常時表示。
- Chromeの実タブ・ピン留め・色付きタブグループを表示。タブの切替・閉じる・ドラッグでの並べ替えとグループ移動に対応。
- Work / Personal / Studioごとにテーマと取り込みブックマークを保存。
- ブックマークバーをフォルダ構造付きで取り込み。確認画面はファビコン＋サイト名、取り込み後は上部ギャラリーに表示。初期6項目から展開・縮小できます。
- 取り込みは元のブックマークを変更せず、リンクも一括で開きません。再取り込みは選択中プロファイルの取り込み一覧を置き換えます。
- 新規タブを検索欄付きSideflowページに置き換えます。

## 対応範囲・既知の制限

HTTP/HTTPSページとSideflowの新規タブが対象です。`chrome://extensions`、Chrome設定、Webストア、他の拡張のページにはUIを埋め込めません。対応しない画面や読み込みに失敗した画面で拡張アイコンを押すと案内ページを開きます。標準サイドパネルへの自動切替は行いません。

別の拡張が新規タブを置き換えている場合は競合します。シークレットの新規タブは置き換えられません。サイトへのアクセスが許可されていないページでは動作しません。

プロファイルは拡張内の設定です。Chromeの実タブ（ピン留め含む）・Cookie・ログイン状態は分離しません。Chrome上部のタブバーも非表示にできません。

物理トラックパッドの感触やOS／Chromeの履歴ジェスチャーとの干渉は未検証です。ページ自体の横スクロールと競合することがあります。自動テストの成功は全サイト・実機での動作保証ではありません。初回配布はプレリリースです。

## データと権限

設定・取り込んだブックマークは端末内の `chrome.storage.local` に保存します。タブとグループ、ブックマークをChrome APIから取得します。解析用の外部送信は行いません。検索確定時は入力URLまたはGoogle検索へ移動します。ファビコンはChromeのキャッシュを利用します。

`tabs` / `tabGroups` / `bookmarks` / `storage` / `favicon` は一覧表示・操作と設定保存に使用します。HTTP/HTTPSのホスト権限と `scripting` はページ内表示と既存タブへの読み込みに使用します。`sidePanel` は過去版との設定互換用に残っていますが、自動表示には使用しません。

## 開発・検証

Node.js 22.12以上、Python 3が必要です。

```sh
npm ci
npx playwright install chromium
npm run dev
npm run check
npm run test:ui
npm run package
```

`npm run dev` はサンプルデータを使うUIプレビューです。実タブ操作・ページ上のスワイプ表示はビルドした拡張で確認してください。

`npm run check` はビルドと単体テスト、`npm run test:ui` はUIと独立したChromiumプロファイル上の拡張操作テストを実行します。通常利用中のChromeプロファイルは変更しません。

`npm run package` は `artifacts/sideflow-<version>.zip` とSHA-256を生成します。GitHub Actionsもビルド・テスト・成果物生成を行います。詳しくは [RELEASE.md](RELEASE.md) を参照してください。
