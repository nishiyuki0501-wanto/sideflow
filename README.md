# Sideflow

Chrome標準サイドパネルにタブとブックマークを表示する拡張です。Arc / Diaの公式製品ではありません。

[配布版 v1.0.21](https://github.com/nishiyuki0501-wanto/sideflow/releases/tag/v1.0.21)

## インストール・更新

ZIPを解凍し、Chromeの拡張管理画面で「パッケージ化されていない拡張機能を読み込む」からsideflow-extensionを選びます。更新は同じフォルダに上書きして既存のSideflowを再読み込みしてください。

v1.0.20以前から更新する場合、既存ページに旧版のサイドバーが残るのでWebページも一度再読み込みしてください。新規タブは開き直してください。タブ・設定・取り込み済みブックマークは既存の拡張ストレージを引き継ぎます。

## 開き方と配置

- ツールバーのSideflowアイコン、Alt/Option＋Shift＋S、または新規タブの「サイドバーを開く」で標準サイドパネルを開きます。
- 閉じるにはChromeのサイドパネル上部の×を使います。
- 左右の配置はChromeの設定で変更します。パネル幅はChromeの境界をドラッグして変更できます。
- パネルはウィンドウ全体で利用し、タブ切替後も表示を維持します。

Chrome自身が本文の表示領域を分割します。ページDOMへの埋め込み、余白追加、縮小、スクロールの変更は行いません。サイトは表示幅に応じて通常のレスポンシブ表示になります。

ページ端のホバー・スワイプによる開閉、下ドック、拡張内での左右切替は廃止しました。以前の配置・常時表示設定は標準パネルの表示に使いません。

## 機能

- 実タブの切替、閉じる、並べ替え、タブグループ操作。
- Work / Personal / Studioごとのテーマと取り込みブックマーク。CookieとChromeの実タブは共有します。
- ブックマークバーをフォルダ構造付きで取り込み。初期状態は全選択、個別解除・全選択・全解除に対応し、元のブックマークは変更しません。
- 新規タブの検索、4色テーマ、見出し編集と保存。
- 内蔵広告ブロック、サイトごとの除外、全体オン／オフ。すべての広告や余白除去には対応しません。

## 権限とデータ

sidePanel、tabs、tabGroups、bookmarks、storage、faviconはパネル表示と端末内保存に使用します。declarativeNetRequestとHTTP/HTTPSのホスト権限は広告ブロック用です。ページへコードを埋め込むscripting権限は削除しました。設定・ブックマークの解析用外部送信は行いません。検索確定時はGoogle検索または入力URLへ移動します。

## 開発・検証

Node.js 22.12以上、Python 3が必要です。

```sh
npm ci
npx playwright install chromium
npm run dev
npm run check
npm run test:ui
npm run package
```

開発サーバーはサンプルデータのUIプレビューです。プレビュー内の左右・下ドック切替は開発用で、配布版は標準サイドパネルです。自動検証は独立したChromiumプロファイルを使い、通常のChromeプロファイルは変更しません。
